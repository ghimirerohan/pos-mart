GET — Try it out calls your real Frappe site (live data). Use Authorize with token your_api_key:your_api_secret (User → API Access).
POST / PUT / DELETE / PATCH to /api/* are blocked in this page and return static mock JSON only — no documents are created or changed.
Session: Token auth is header-only; it does not log you into the POS app or Desk — you still log in normally at /klik_pos or /login.
